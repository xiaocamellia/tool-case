## 1. 项目概述

### 1.1 产品定位

**「设计师的工程计算瑞士军刀」**

不是复杂的仿真软件，也不是笨重的Excel表格——而是一个轻量、快速、专业的指标计算工具集，把你每天都要用的工程计算集中在一起，输入参数秒出结果。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| **省时** | 不用再翻手册、找公式、编Excel，打开就能算 |
| **准确** | 公式内置，避免手算出错、单位搞错 |
| **规范** | 计算过程可追溯，结果格式统一 |
| **积累** | 常用参数可保存，下次直接用 |
| **分享** | 计算结果可一键导出，方便写报告、做汇报 |

### 1.3 设计原则

1. **开箱即用**：每个计算器打开就能用，不需要学习
2. **专业准确**：公式经过验证，符合工程实际
3. **灵活扩展**：计算器可插拔，方便后续新增
4. **结果友好**：不仅给数字，还要给解释、给结论
5. **离线可用**：纯前端计算，断网也能用

## 3. 核心计算器详细设计

### 3.1 天线增益估算

#### 3.1.1 功能说明

根据天线口径、工作频率、效率等参数，快速估算天线理论增益和波束宽度。

#### 3.1.2 输入参数

| 参数 | 单位 | 说明 | 默认值 |
|------|------|------|--------|
| 工作频率 | GHz / MHz / kHz | 自动单位转换 | 10 GHz |
| 口径尺寸（D） | m / cm / mm | 圆形口径直径 | 0.5 m |
| 口径效率（η） | % | 一般50%-70% | 60% |
| 口径形状 | - | 圆形 / 矩形 / 椭圆形 | 圆形 |
| （矩形）长×宽 | m × m | 矩形口径时填写 | - |

#### 3.1.3 输出结果

| 结果 | 单位 | 公式 |
|------|------|------|
| 天线增益 | dBi | G = 10log₁₀(η × (πD/λ)²) |
| 方位面3dB波束宽度 | ° | θ₃dB ≈ 70° × λ/D（圆形） |
| 俯仰面3dB波束宽度 | ° | 矩形口径时分别计算 |
| 第一副瓣电平 | dB | 均匀照射约-13.2dB |
| 口径面积 | m² | - |
| 波长 | mm / cm | λ = c/f |

#### 3.1.4 附加功能

- **快速对比**：输入两组参数，自动对比增益差异
- **反算功能**：已知增益，反算需要的口径尺寸
- **常见天线参考**：喇叭、抛物面、平板阵列等典型效率参考值

---

### 3.2 作用距离估算（雷达方程）

#### 3.2.1 功能说明

基于雷达方程，估算雷达最大探测距离。支持单站雷达、双站雷达两种模式。

#### 3.2.2 输入参数

| 参数 | 单位 | 说明 | 默认值 |
|------|------|------|--------|
| **发射端** | | | |
| 发射功率（Pt） | W / kW / dBm | 峰值功率或平均功率 | 100 W |
| 发射天线增益（Gt） | dBi | | 30 dBi |
| **接收端** | | | |
| 接收天线增益（Gr） | dBi | 单站时=Gt | 30 dBi |
| 接收带宽（B） | MHz / kHz | | 10 MHz |
| 噪声系数（NF） | dB | | 3 dB |
| 检测信噪比（SNR_min） | dB | 检测门限 | 10 dB |
| **目标** | | | |
| 目标RCS（σ） | m² / dBsm | | 1 m² |
| **环境** | | | |
| 工作频率（f） | GHz | | 10 GHz |
| 系统损耗（L） | dB | 各类损耗总和 | 3 dB |
| 积累增益（Ci） | dB | 脉冲积累增益 | 0 dB |

#### 3.2.3 输出结果

| 结果 | 单位 | 公式 |
|------|------|------|
| 最大探测距离（R_max） | km / m | R⁴ = Pt·Gt·Gr·λ²·σ / ((4π)³·k·T₀·B·NF·SNR_min·L) |
| 接收功率（Pr） | dBm / W | 距离为R时的接收功率 |
| 噪声功率（Pn） | dBm / W | 接收机噪声基底 |
| 动态范围 | dB | 接收功率变化范围 |
| 距离-功率曲线 | 图表 | 距离从0到R_max的功率变化 |

#### 3.2.4 附加功能

- **距离反算**：给定距离，算接收功率和SNR
- **参数扫描**：某个参数变化时，距离怎么变（如：功率从10W变到100W，距离增加多少？）
- **多目标对比**：不同RCS目标的探测距离对比表
- **损耗分解**：各项损耗分别占多少，一目了然

#### 3.3.1 功能说明

通信链路预算计算，计算接收端信噪比、余量等。

#### 3.3.2 输入参数

| 参数 | 单位 | 说明 |
|------|------|------|
| **发射端** | | |
| 发射功率 | dBm / W | |
| 发射天线增益 | dBi | |
| 发射馈线损耗 | dB | |
| **信道** | | |
| 工作频率 | GHz | |
| 通信距离 | km | |
| 自由空间损耗 | dB | 自动计算 |
| 大气损耗 | dB | 可选，按经验值或模型 |
| 雨衰 | dB | 可选，按降雨率计算 |
| 多径衰落余量 | dB | |
| **接收端** | | |
| 接收天线增益 | dBi | |
| 接收馈线损耗 | dB | |
| 接收机噪声系数 | dB | |
| 接收带宽 | MHz | |
| 所需Eb/N0 | dB | 根据调制方式和误码率 |

#### 3.3.3 输出结果

| 结果 | 单位 | 说明 |
|------|------|------|
| 接收功率 | dBm | 接收机输入端功率 |

| 接收Eb/N0 | dB | 比特能量噪声比 |
| 链路余量 | dB | 超出所需的余量（正值表示够用） |

#### 3.3.4 附加功能

- **瀑布图展示**：从发射到接收，各项增益损耗一目了然
- **灵敏度反算**：已知链路余量，反算接收机灵敏度要求

- **最大通信距离**：余量为0时的距离

### 3.4 测向精度估算

#### 3.4.1 功能说明

估算干涉仪测向系统的理论测向精度，支持相位干涉仪、比幅测向等多种体制。

#### 3.4.2 输入参数

| 参数 | 单位 | 说明 |
|------|------|------|
| **阵列配置** | | |
| 测向体制 | - | 相位干涉仪 / 比幅测向 / MUSIC / ESPRIT |
| 基线长度（d） | λ / m | 以波长为单位或长度单位 |
| 阵元数（N） | 个 | 阵列单元数 |
| 基线构型 | - | 均匀线阵 / L型 / 圆阵 / 十字阵 |
| **信号条件** | | |
| 信噪比（SNR） | dB | 接收端信噪比 |
| 快拍数（K） | 次 | 采样快拍数 |
| 工作频率 | GHz | |
| **系统误差** | | |
| 通道不一致性 | ° / dB | 幅相误差 |
| 测角范围 | ° | 如 ±60° |

#### 3.4.3 输出结果

| 结果 | 单位 | 公式/说明 |
|------|------|-----------|
| 理论测向精度（RMSE） | ° | 相位干涉仪：σ_θ ≈ λ / (2π·d·√(2·SNR)) |
| 克拉美罗界（CRB） | ° | 理论下界，最优算法能达到的极限 |
| 方位面精度 | ° | |
| 俯仰面精度 | ° | 二维阵列时输出 |
| 测角范围 | ° | 无模糊测角范围 |
| 模糊数 | 个 | 基线过长时的相位模糊数 |
| 精度-角度曲线 | 图表 | 不同来波方向的测向精度变化 |

#### 3.4.4 附加功能

- **多算法对比**：同一阵列，不同算法的精度对比
- **基线设计**：给定精度要求，反推需要的基线长度
- **误差源分解**：SNR、通道不一致、量化误差分别贡献多少
- **SNR扫描**：不同SNR下的精度变化曲线

### 3.5 单位转换器

#### 3.5.1 功能说明

工程中常用的单位转换，一站式搞定，不用再百度换算。

#### 3.5.2 支持的转换类型

| 类别 | 转换内容 |
|------|----------|
| **频率 ↔ 波长** | Hz / kHz / MHz / GHz ↔ m / cm / mm / μm |
| **功率 ↔ dBm** | W / mW / kW ↔ dBm / dBW |
| **角度 ↔ 弧度** | ° / ′ / ″ ↔ rad / mrad |
| **长度** | m / cm / mm / μm / nm / 英寸 / 英尺 |
| **电压 ↔ dBuV** | V / mV / μV ↔ dBuV / dBmV |
| **增益 ↔ 倍数** | dB ↔ 倍数（×） |
| **温度** | ℃ / ℉ / K |
| **数据率** | bps / kbps / Mbps / Gbps |
| **面积** | m² / cm² / mm² |

#### 3.5.3 特色功能

- **智能识别**：输入数字+单位，自动识别并转换
- **常用值速查**：常见频率对应的波长（如10GHz=3cm）
- **复制即用**：点击结果自动复制到剪贴板
- **历史记录**：最近转换的10条记录

### 4.2 核心交互设计

#### 4.2.1 实时计算

- **边输边算**：输入参数变化，结果实时更新，不用点"计算"按钮
- **单位切换**：切换单位，数值自动换算
- **智能默认**：常用参数给默认值，减少输入

#### 4.2.2 结果展示

- **重点突出**：核心结果用大字号、彩色突出显示
- **分级展示**：核心结果 → 详细结果 → 计算过程（可展开）
- **状态指示**：
  - 🟢 绿色：正常、充足
  - 🟡 黄色：临界、勉强
  - 🔴 红色：不足、超标

#### 4.2.3 历史记录

- 自动保存最近20次计算
- 点击历史记录，一键恢复当时的参数和结果

### 5.1 计算器定义结构

```typescript
interface Calculator {
    id: string;              // 唯一标识
    name: string;            // 计算器名称
    category: string;        // 分类
    description: string;     // 说明
    icon: string;            // 图标
$1
    // 输入参数定义
    inputs: InputParam[];
$1
    // 输出结果定义
    outputs: OutputParam[];
$1
    // 计算函数
    calculate: (inputs: Record<string, number>) => Record<string, number>;
$1
    // 是否支持图表
    supportChart: boolean;
    chartType?: 'line' | 'bar' | 'pie';
}

interface InputParam {
    id: string;
    name: string;            // 参数名称
    unit: string;            // 默认单位
    unitOptions?: string[];  // 可选单位
    defaultValue: number;    // 默认值
    min?: number;            // 最小值
    max?: number;            // 最大值
    step?: number;           // 步长
    type: 'number' | 'select' | 'boolean';
    options?: {label: string, value: any}[];  // 下拉选项
    description?: string;    // 参数说明
    group?: string;          // 分组
}

interface OutputParam {
    id: string;
    name: string;            // 结果名称
    unit: string;            // 单位
    format: string;          // 显示格式，如 '0.00'
    isCore: boolean;         // 是否核心结果（突出显示）

        good: number;        // 大于此值为良好（绿色）

    };
}
```

## 8. 附录：核心公式参考

### 8.1 天线增益

$$ G = \eta \cdot \left( \frac{\pi D}{\lambda} \right)^2 $$

- G：天线增益（倍数）
- η：口径效率
- D：口径直径
- λ：波长

**dB形式**：
$$ G_{dBi} = 10\log_{10}(\eta) + 20\log_{10}\left( \frac{\pi D}{\lambda} \right) $$

### 8.2 雷达方程

$$ R_{max}^4 = \frac{P_t \cdot G_t \cdot G_r \cdot \lambda^2 \cdot \sigma}{(4\pi)^3 \cdot k \cdot T_0 \cdot B \cdot NF \cdot SNR_{min} \cdot L} $$

- R_max：最大探测距离
- Pt：发射功率
- Gt, Gr：发射/接收天线增益
- λ：波长
- σ：目标RCS
- k：玻尔兹曼常数 (1.38×10⁻²³ J/K)
- T0：标准温度 (290K)
- B：带宽
- NF：噪声系数
- SNR_min：最小可检测信噪比
- L：系统损耗

### 8.3 自由空间损耗

$$ L_{fs} = 20\log_{10}\left( \frac{4\pi d}{\lambda} \right) = 32.45 + 20\log_{10}(f_{MHz}) + 20\log_{10}(d_{km}) $$

### 8.4 相位干涉仪测向精度

单基线相位干涉仪：
$$ \sigma_\theta \approx \frac{\lambda}{2\pi d \cdot \sqrt{2 \cdot SNR}} $$

- σ_θ：测向角误差（弧度）
- d：基线长度
- SNR：信噪比

**克拉美罗界（CRB）**：
$$ CRB(\theta) = \frac{1}{K \cdot SNR} \cdot \frac{\lambda^2}{8\pi^2 d^2 \cos^2\theta} $$

- K：快拍数

### 8.5 噪声功率

$$ P_n = k \cdot T \cdot B \cdot NF $$

- k = -228.6 dBW/(Hz·K) = -198.6 dBm/(Hz·K)
- 室温(290K)下噪声谱密度：-174 dBm/Hz

## 📌 文档总结

### 核心亮点

1. **专业全面**：覆盖天线、雷达、通信、测向、系统等各领域常用计算
