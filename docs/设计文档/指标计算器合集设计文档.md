> 适用版本：V1.2.1（`radar_tool/__init__.py`：`__version__ = "1.2.1"`）
> 主要源码：`radar_tool/calc_panel.py`、`radar_tool/calc_ui.py`、`radar_tool/calc_formulas.py`、`radar_tool/calc_units.py`
> 所属页签：指标计算器（`main_window.py` 第 6 个页签 `🧮 指标计算器`，面板类 `CalcPanel`）
> 回归测试：`tests/test_calc_link_budget.py`、`tests/test_df_accuracy.py`、`tests/test_array_param_calc.py`、`tests/test_unit_conversion.py`

## 1. 背景与目标

### 1.1 文档定位

本文档是「指标计算器合集」的**工程实现文档**，以 V1.2.1 实际代码为准：类名、函数名、公式（符号、常数、单位）均与 `calc_formulas.py` / `calc_units.py` / `calc_ui.py` 逐行核对一致。本模块早期文档（v1.0）是产品设计提案（设想 Vue 3 + TypeScript + ECharts 前端，含参数扫描、历史记录、功耗/重量预算等大量规划）。本文档只写**已落地**内容；未实现项统一收进 §6.3 与 §8 并标注「未落地」，不作为交付承诺。同时完整记录 2026-11 项目体检 P0 阶段对本模块四处公式错误的修正（§6.1）与对应回归测试（§7）。

### 1.2 背景

载荷（雷达/通信/电子对抗）设计师日常反复手算天线增益、作用距离、链路预算、测向精度等指标，翻手册、编 Excel、手算易错且单位换算繁琐。本模块把高频公式集中到一个面板：填参数 → 点计算 → 出结果/公式/状态提示，纯离线。2026-11-05 项目体检（`PROJECT_AUDIT_ACTION_PLAN.md`）将「计算公式」列为 P0，发现链路预算固定码率、测向精度缺 `cos(θ)` 项、阵列构型混用公式、单位换算输入域缺失等问题，在 P0 第二阶段（步骤 4~7）修正并建立 4 个回归测试防回退。

### 1.3 目标与范围

目标：① 7 类高频指标开箱即用（有默认值、点按钮即算）；② 公式与单位换算下沉为**无 Qt 依赖纯函数**（可单测、可复用，`radar_tool/coord_core/conventions.py` 即复用 `calc_units.convert_angle`）；③ 输入错误以领域异常在结果区明确展示，不产生未处理异常。

范围（V1.2.1 已实现）：7 个计算器；3 个纯公式函数 `calculate_link_budget` / `calculate_df_accuracy` / `calculate_array_parameters`；7 个单位换算纯函数 + 校验助手 `_finite_value` / `_positive_value` + 常数 `C`、`K_BOLTZ`。不在范围：参数扫描、历史记录、收藏模板、图表、导出、自定义计算器、计算器联动、功耗/重量预算等（见 §6.3/§8）。

## 2. 总体架构

### 2.1 在工具箱中的位置

本模块是 `MainWindow` 第 6 个功能页签，按「一个面板 + 一个工厂方法」接入：

```python
# radar_tool/main_window.py
def _create_calc_tab(self):
    from .calc_panel import CalcPanel   # 懒加载：首次切换到该页签才导入/实例化
    return CalcPanel(self)
```

要点：页签顺序为 数据可视化处理 / 数据真值复核 / 干涉仪测向仿真 / 测向校正自动化 / 📡阵列设计助手 / **🧮指标计算器** / 格式转换 / 📋试验记录助手 / 📐坐标系账本；面板构造签名 `CalcPanel(parent)` 与其余页签一致；计算全部在 UI 线程同步完成（纯公式，微秒级），不用 `background_tasks.TaskRegistry`；本模块无任何持久化，不涉及 `schemas.py` / `export_safety.py` / `runtime_paths.py`。

### 2.2 模块结构表

| 文件 | 职责 | Qt 依赖 |
|---|---|---|
| `calc_panel.py`（25 行） | **兼容门面**（docstring "Compatibility facade for calculator UI, units, and pure formulas."）：从 `calc_formulas`/`calc_units`/`calc_ui` re-export 全部公开名称到 `__all__`，保留历史导入路径 | 仅转发 |
| `calc_formulas.py`（317 行） | 纯公式层：`calculate_link_budget`、`calculate_df_accuracy`、`calculate_array_parameters`，含输入域校验，返回结果字典 | 否 |
| `calc_units.py`（149 行） | 单位换算与校验层：常数 `C=3e8`、`K_BOLTZ=1.38e-23`；`_finite_value`/`_positive_value`；`convert_temperature`/`convert_angle`/`convert_power`/`convert_gain_ratio`/`convert_frequency_wavelength`/`convert_length`/`convert_unit` | 否 |
| `calc_ui.py`（883 行） | 界面控件层：`CalcPanel`、`_BaseCalc` 与 `_UnitConverter`、`_AntennaGainCalc`、`_RadarRangeCalc`、`_LinkBudgetCalc`、`_DFAccuracyCalc`、`_ArrayParamCalc`、`_SNRCalc` | PyQt5、numpy |

分层原则（体检 P2 步骤 11 确立）：公式与单位换算是纯函数，UI 只取值/展示。`calc_panel.py` 门面使既有导入（含回归测试的 `from radar_tool.calc_panel import ...`）在拆分后保持可用。

### 2.3 计算器注册/分发机制（按实际代码）

无插件式注册表，采用**硬编码列表 + 索引对齐**（导航行号 = 堆栈页序 = `calc_widgets` 键）：

1. **导航注册**（`CalcPanel._init_ui`）：7 个 `(显示名, idx)` 元组写死在 `calculators` 列表，逐项 `QListWidgetItem` 加入 `nav_list`，索引存 `Qt.UserRole`——`🔧 单位转换器(0)`、`📡 天线增益估算(1)`、`🎯 作用距离估算(2)`、`📶 链路预算(3)`、`🧭 测向精度估算(4)`、`📊 阵列参数计算(5)`、`🔊 信噪比计算(6)`；
2. **控件注册**（`_create_all_calculators`）：`self.calc_widgets[0..6]` 依次 = `_UnitConverter()`、`_AntennaGainCalc()`、`_RadarRangeCalc()`、`_LinkBudgetCalc()`、`_DFAccuracyCalc()`、`_ArrayParamCalc()`、`_SNRCalc()`，按 key 顺序 `stack.addWidget`；
3. **切换分发**：`nav_list.currentRowChanged → _switch_calc(idx)` → `stack.setCurrentIndex(idx)`；
4. **单位换算分发**：`convert_unit(category, value, source_unit, target_unit)` 按 category 转发——0 频率↔波长→`convert_frequency_wavelength`、1 功率↔dBm→`convert_power`、2 角度↔弧度→`convert_angle`、3 增益↔倍数→`convert_gain_ratio`、4 温度→`convert_temperature`、5 长度→`convert_length`，其他 `ValueError('不支持的转换类型')`。UI 侧 `_UnitConverter.combo_type` 索引与 category 同步；
5. **公式计算分发**：链路预算/测向精度/阵列参数 3 个计算器的 `_on_calc` 调 `calc_formulas.py` 纯函数；天线增益/作用距离/信噪比的计算内联在 `_on_calc`（尚未抽纯函数，见 §8）。

## 3. 数据模型

### 3.1 计算器定义结构（`_BaseCalc` 契约）

无 TS `Calculator` 接口或 JSON 定义；每个计算器是 `calc_ui.py` 中一个 `_BaseCalc(QWidget)` 子类，约定：

| 成员 | 约定 |
|---|---|
| `__init__(self, title, parent=None)` | 子类传标题，基类构造调用 `_build()` |
| `_build()` | 垂直布局：标题 QLabel → `QScrollArea` 输入容器 → `formula_label` 公式条 → 「计算结果」QGroupBox + `result_text`（QTextEdit 只读、max 高 200px、Consolas 10） |
| `_build_inputs()` | **子类重写**：把输入控件加入 `self.main_layout` |
| `set_formula(text)` | 基类：公式条文本，自动加 `📐 公式：` 前缀 |
| `_show_result(lines)` | 基类：行协议→HTML——`## x` 蓝色 h3、`**x**` 加粗、含 🔴/❌ 红、🟢/✅ 绿、🟡 黄、`键: 值` 灰键黑粗值、其他灰正文 |
| `_on_calc() -> bool` | **子类重写**：成功 `True`；输入错误 `False`（结果区显示 `❌`+错误文案，不抛异常） |
| `self.last_result` | `_LinkBudgetCalc`/`_DFAccuracyCalc`/`_ArrayParamCalc` 缓存纯函数返回字典，失败置 `None` |

### 3.2 纯函数输入输出字段

**`calculate_link_budget(pt_dbm, gt_dbi, lt_db, freq_ghz, distance_km, gr_dbi, lr_db, nf_db, bandwidth_mhz, ebn0_req_db, rate_bps)`** —— 参数单位依次为 dBm、dBi、dB、GHz、km、dBi、dB、dB、MHz、dB、bps（全部须有限；`freq_ghz/distance_km/bandwidth_mhz/rate_bps` 须 > 0）。返回键：`frequency_hz`、`distance_m`、`bandwidth_hz`、`rate_bps`、`wavelength_m`、`free_space_loss_db`、`receive_power_dbm`、`receive_power_dbw`、`noise_power_dbm`、`noise_power_dbw`、`carrier_to_noise_db`、`eb_to_n0_db`、`ebn0_req_db`、`margin_db`。

**`calculate_df_accuracy(baseline_lam, element_count, snr_db, snapshots, theta_deg, algorithm)`** —— 参数：基线长度 λ（>0）、阵元数（int ≥2）、SNR dB、快拍数（int ≥1）、来波方向 °（须 −90<θ<90）、算法名（含子串 `MUSIC` 即视为 MUSIC）。返回键：`baseline_lam`、`element_count`、`snr_db`、`snr_linear`、`snapshots`、`theta_deg`、`theta_rad`、`cos_theta`、`singular`、`sigma_interfer_rad`、`sigma_interfer_deg`、`crb_rad2`、`crb_deg`、`algorithm`、`is_music`、`music_applicable`、`music_gain`、`music_status`、`estimated_rmse_deg`、`ambiguity_range_deg`、`side_fire_warning`。

**`calculate_array_parameters(config, element_count, spacing_lam, frequency_hz, element_gain, radius_lam=None, rows=None, cols=None, dx_lam=None, dy_lam=None)`** —— `config` 前缀分派：`'均匀线阵'`/`'矩形面阵'`/`'均匀圆阵'`，否则 `ValueError('未知阵列构型')`；`element_count` int ≥2（RECT 返回值用 `rows*cols`）、`spacing_lam`/`radius_lam`/`dx_lam`/`dy_lam` 以 λ 计（>0）、`frequency_hz` >0（校验后不参与 λ 归一公式）、`element_gain` 有限（dBi）。返回键：`array_type`（ULA/RECT/UCA）、`element_count`、`gain_db`、`beamwidth_deg`、`beamwidth_az_deg`、`beamwidth_el_deg`、`aperture`、`aperture_x`、`aperture_y`、`grating_angle_deg`、`unambig_deg`、`warning`、`formula`。

### 3.3 单位换算表（`calc_units.py`）

常数：`C = 3e8`（m/s，λ=C/f）、`K_BOLTZ = 1.38e-23`（J/K）。校验助手：`_finite_value(value, name)`（float 且 isfinite，否则 `ValueError(f'{name}必须是有限数值')`）、`_positive_value(value, name)`（>0，否则 `f'{name}必须大于 0'`）。

| 函数 | 支持单位 | 关键规则 |
|---|---|---|
| `convert_frequency_wavelength` | Hz/kHz/MHz/GHz ↔ m/cm/mm | 同域系数换算 + 跨域 λ=C/f；值须为正 |
| `convert_power` | W/mW ↔ dBm/dBW | 线性功率须为正；dBm→W 用 `10^((dBm-30)/10)`，dBW→W 用 `10^(dBW/10)` |
| `convert_angle` | °/rad/mrad | 以 rad 枢纽；允许负值，拒绝 NaN/Inf |
| `convert_gain_ratio` | dB ↔ 倍数 | **倍数须 > 0**（0/负数报错，不返回 0 dB）；功率比口径 `10·log10` |
| `convert_temperature` | ℃/℉/K | K 输入须为正；换算结果须 > 0 K |
| `convert_length` | m/cm/mm/km/英寸/英尺 | 以 m 为基准系数（英寸 39.3701/m、英尺 3.28084/m）；值须为正 |
| `convert_unit(category,…)` | 上述 6 类统一入口 | `OverflowError`→`ValueError('换算结果超出可表示范围')`；结果再经 `_finite_value` 复核 |

### 4.1 单位转换器（`_UnitConverter` → `convert_unit` 等）

公式提示（`_update_formula`，按类型）：频率↔波长 `lam=c/f | f=c/lam`；功率 `dBm=10*log10(P/1mW) | P(mW)=10^(dBm/10) | P(W)=10^((dBm-30)/10)`；角度 `rad=deg*pi/180 | deg=rad*180/pi | mrad=rad*1000 | rad=mrad/1000`；增益 `倍数=10^(dB/10) | dB=10*log10(倍数)，倍数必须 > 0`；温度 `F=C*9/5+32 | K=C+273.15 | C=(F-32)*5/9`；长度 `V2=V1*(factor2/factor1)`。

符号/规则见 §3.3。输入域：值须有限浮点；频率/波长/线性功率/长度/倍数/K 须为正；角度允许负值但拒绝 NaN/Inf；温度结果须 > 0 K。实现函数：`convert_unit` → `convert_frequency_wavelength`/`convert_power`/`convert_angle`/`convert_gain_ratio`/`convert_temperature`/`convert_length`。界面：成功显示 `## 转换结果` + `{value:g} {src} = {result:.6g} {dst}`；辅助按钮 `_clear_input`（清空）、`_swap_units`（互换单位）；类型切换 `_on_type_changed` 联动 `_update_units`（重建单位列表，目标默认第 2 项）与 `_update_formula`。

### 4.2 天线增益估算（`_AntennaGainCalc`，计算内联于 `_on_calc`）

公式（界面公式条）：`G(dBi) = 10*log10(4pi*Ae/lam^2) = 10*log10(n*(pi*D/lam)^2)    |    theta3dB ~= 70*lam/D`。实现：`lam = C/f`；`area = π(D/2)²`；`A_eff = η·π(D/2)²`；`G_lin = 4π·A_eff/λ²`（≡ `η(πD/λ)²`）；`G_dBi = 10·log10(G_lin)`；`theta_3dB = 70·λ/D`。

符号：`f` 工作频率 Hz（GHz/MHz 换算）、`D` 口径直径 m（m/cm/mm 换算）、`η` 口径效率 0~1、`λ` 波长 m、`A_eff` 有效面积 m²。输入域：频率、直径 `_positive_value`；效率 `0 < η ≤ 1`（否则 `ValueError('口径效率必须在 0~100% 之间')`）；异常捕获 `(ValueError, OverflowError, ZeroDivisionError)`。输出：波长（mm/cm）、口径/有效面积、增益（dBi 与倍数）、3dB 波束宽度、第一副瓣电平「-13.2 dB (均匀照射)」（固定文案）、提示「实际增益需考虑馈线损耗、照射锥削等因素」。注意：`combo_shape`（圆形/矩形/椭圆形）**不参与计算**，恒按圆形口径（见 §8）。

### 4.3 作用距离估算（`_RadarRangeCalc`，计算内联于 `_on_calc`）

公式（界面公式条）：`Rmax = [Pt*Gt*Gr*lam^2*sigma / ((4pi)^3*k*T0*B*NF*SNRmin*L)]^(1/4)`。实现：`Gt=10^(gt/10)`、`Gr`、`NF`、`SNR_min`、`L` 同理线性化；`lam=C/f`；`Pn = K_BOLTZ·T0·B·NF`（`T0 = 290` 硬编码）；`R4 = Pt·Gt·Gr·λ²·σ / ((4π)³·Pn·SNR_min·L)`；`R_max = R4**0.25`（R4>0，否则 0）；固定 10 km 参考（`R_10km = 10000` 硬编码）算 `Pr_10km = Pt·Gt·Gr·λ²·σ/((4π)³·R_10km⁴·L)` 与 `SNR_10km = Pr_10km/Pn`。

符号：`Pt` W、`Gt/Gr` dBi、`f` Hz、`σ` RCS m²、`B` Hz、`NF` dB、`SNR_min` dB、`L` dB。输入域：功率/频率/RCS/带宽 `_positive_value`，增益/噪声系数/SNR/损耗 `_finite_value`。输出：R_max（km/m）、Pn（dBm）、10 km 处 Pr 与 SNR，及「参数变化影响」提示：功率×4 / 增益×4 / RCS×4 → 距离×`4**0.25`（≈1.41，四次方根关系）。

### 4.4 链路预算（`_LinkBudgetCalc` → `calculate_link_budget`）

公式（界面公式条，`calc_formulas.py:6`）：

```
Pr(dBm) = Pt+Gt-Lt-Lfs+Gr-Lr    |    Lfs = 20*log10(4πd/λ)
Eb/N0 = C/N - 10*log10(B/Rb)    |    余量 = Eb/N0 - EbN0_req
```

计算链（实现逐行对应）：`frequency_hz=freq_ghz×1e9`、`distance_m=distance_km×1e3`、`bandwidth_hz=bandwidth_mhz×1e6`；`wavelength_m=C/frequency_hz`；`free_space_loss_db=20·log10(4π·distance_m/wavelength_m)`；`receive_power_dbm=pt_dbm+gt_dbi−lt_db−free_space_loss_db+gr_dbi−lr_db`；`noise_power_dbm=−174+10·log10(bandwidth_hz)+nf_db`；`carrier_to_noise_db=receive_power_dbm−noise_power_dbm`；`eb_to_n0_db=carrier_to_noise_db−10·log10(bandwidth_hz/rate_bps)`；`margin_db=eb_to_n0_db−ebn0_req_db`；另返 `receive_power_dbw=receive_power_dbm−30`、`noise_power_dbw=noise_power_dbm−30`。

符号：`Pt` dBm、`Gt/Gr` dBi、`Lt/Lr` 收发馈线损耗 dB、`d` km、`f` GHz、`B` MHz、`NF` dB、`EbN0_req` dB、`Rb` bps；−174 dBm/Hz 为 290 K 噪声谱密度。输入域：全部 11 参数须有限（`ValueError(f'{名称}必须是有限数值')`）；频率/距离/带宽/码率须 > 0（文案含「必须大于 0 …」）。界面结果：状态三档 `margin>5`🟢充足 / `>0`🟡临界 / 否则🔴不足；展示 EIRP（`pt+gt−lt`）、Lfs、Pr/Pn（dBm 与 dBW）、C/N、Eb/N0（含需求）、余量、频率/带宽/码率换算明细与「链路瀑布」（发射→信道→接收）。`last_result` 缓存返回字典。本节为体检步骤 4 修正对象（原固定 `Rb=B` 使 Eb/N0 退化为 C/N），见 §6.1。

### 4.5 测向精度估算（`_DFAccuracyCalc` → `calculate_df_accuracy`）

公式（界面公式条，`calc_formulas.py:83`）：

```
σ_int(rad) = 1/[2π·d·cos(θ)·√(2·SNR_lin)]
CRB(rad²) = 1/[K·SNR_lin·8π²·d²·cos²(θ)]
SNR_lin = 10^(SNR_dB/10)，K = 快拍数
```

计算链：`theta_rad=radians(theta_deg)`、`cos_theta=cos(theta_rad)`、`snr_linear=10**(snr_db/10)`；奇异判据 `singular = abs(cos_theta) < 1e-12`（奇异时 `sigma_interfer_rad=inf`、`crb_rad2=inf`）；`sigma_interfer_rad = 1/(2π·baseline_lam·cos_theta·√(2·snr_linear))`；`crb_rad2 = 1/(snapshots·snr_linear)/(8π²·baseline_lam²·cos_theta²)`；`sigma_interfer_deg=degrees(...)`、`crb_deg=degrees(√crb_rad2)`（有限时）。

MUSIC（`is_music = 'MUSIC' in str(algorithm)`）：收集 `music_reasons`——`element_count<2`「阵元数至少为 2」、`snapshots<2*element_count`「快拍数至少为 2N」、`snr_db<0`「SNR 至少为 0 dB」；`music_applicable = is_music and not music_reasons`；适用时 `estimated_rmse_deg = sigma_interfer_deg/√element_count`、`music_gain = √element_count`，否则 RMSE 不打折、`music_gain = 1.0`；`music_status` 按情形输出「不适用（原因）」/「适用（窄带、非相关信源、阵列已校准）」/「未选择」。另：`side_fire_warning = abs(theta_deg) >= 89`；无模糊范围 `ambiguity_range = degrees(asin(1/(2·baseline_lam)))`（`baseline_lam>0.5`），否则 `90.0`。

符号：`d` 基线长度 λ（波长数归一）、`N` 阵元数、`SNR_dB` 功率比 dB、`K` 快拍数、`θ` 来波方向 °；CRB 以 rad² 得方差下界再开方换算为角度 RMSE（°）。输入域：参数全有限；`baseline_lam>0`（`'基线长度必须大于 0 λ'`）、`element_count≥2`、`snapshots≥1`、`-90<theta_deg<90`（`'来波方向必须满足 -90° < theta < 90°'`，±90° 与超范围抛 `ValueError`）。界面：RMSE、CRB（°）与中间量（rad²）、无模糊范围 ±、SNR 线性定义、K、θ/cos(θ)、MUSIC 条件行；奇异时 `🔴 …公式奇异，误差发散`；`side_fire_warning` 时 `🟡 …接近正侧射，cos(θ)=…，误差显著放大`；未选 MUSIC 提示「当前结果为单基线干涉仪模型」；末尾提示 CRB 是方差下界、SNR+10dB → 误差约降 √10≈3.16 倍。本节为体检步骤 5 修正对象（原缺 `cos(θ)`、MUSIC 无条件开根号），见 §6.1。

### 4.6 阵列参数计算（`_ArrayParamCalc` → `calculate_array_parameters`）

公式（界面公式条，`calc_formulas.py:192`）：`ULA: θ3dB≈50.8/(N·d) | RECT: θ3dB=50.8/(M·dx), 50.8/(N·dy) | UCA: θ3dB≈50.8/(2R)`。通用：`gain_db = element_gain + 10·log10(element_count)`。三分支（`config` 前缀）：

**ULA**（`startswith('均匀线阵')`，`array_type='ULA'`，`d=spacing_lam`）：`aperture=(N−1)·d`（`aperture_x=aperture`、`aperture_y=0`）；`beamwidth=50.8/(N·d)`；栅瓣：`d>1` 时 `grating=degrees(asin(min(1/d,1)))` 且 warning「间距 …λ > 1λ，存在栅瓣」，`0.5<d≤1` 时 `grating=None` 且「…> 0.5λ，无模糊范围收窄」，`d≤0.5` 时「间距 ≤0.5λ，无栅瓣风险」；无模糊 `unambig=degrees(asin(min(1/(2d),1)))`（`d>0.5`）否则 `180.0`；`formula=f'θ3dB=50.8/(N·d)={…:.2f}°'`。

**RECT**（`startswith('矩形面阵')`，`array_type='RECT'`）：`aperture_x=(cols−1)·dx`、`aperture_y=(rows−1)·dy`、`aperture=hypot(...)`；`beamwidth_az=50.8/(cols·dx)`（方位 M=cols）、`beamwidth_el=50.8/(rows·dy)`（俯仰 N=rows）、`beamwidth_deg=min`；栅瓣：`max(dx,dy)>1` 时 `grating=degrees(asin(min(1/max(dx,dy),1)))` 且「存在大于 1λ 的方向间距，可能产生栅瓣」，否则 `None`/「X/Y 间距均不超过 1λ，无一维栅瓣风险」；无模糊取两方向 `degrees(asin(min(1/(2·d),1)))`（`d>0.5` 否则 180）之 `min`；`formula=f'方位θ3dB=50.8/(M·dx)=…，俯仰θ3dB=50.8/(N·dy)=…'`。

**UCA**（`startswith('均匀圆阵')`，`array_type='UCA'`，`R=radius_lam`）：`aperture=aperture_x=aperture_y=2R`；`beamwidth=50.8/(2R)`；`grating=None`、`unambig=None`，warning「圆阵按半径和角间距评估，不套用线阵栅瓣公式」；`formula=f'θ3dB≈50.8/(2R)=…'`。其他 config → `ValueError('未知阵列构型')`。

输入域：`frequency_hz>0` 有限、`element_gain` 有限、`element_count≥2`；ULA `spacing_lam>0`；RECT `rows≥1`、`cols≥1`、`rows*cols≥2`（`'矩形面阵行数×列数必须至少为 2'`）、`dx/dy>0`（`'X/Y 阵元间距必须大于 0'`）；UCA `radius_lam>0`（`'UCA 半径必须大于 0'`）。界面：`_on_config_change` 按构型显隐输入组；`_spacing_lam(value)` 按 `combo_d_unit`（λ/m）换算，`m` 时 `value/(C/frequency_hz)`——ULA `spin_d` 与 RECT `spin_dx/dy` 共用该单位下拉（RECT 模式下隐藏但仍生效），UCA 半径恒以 λ 输入；结果区含构型、阵元数、增益、3dB 波束宽度、公式串、孔径（RECT 另列方位/俯仰波束宽度与 X/Y 孔径）与「栅瓣分析」（warning、第一个栅瓣位置或「不适用」、无模糊范围或「圆阵按全角方向图评估」）。本节为体检步骤 6 修正对象（原三构型混用线阵公式），见 §6.1。

### 4.7 信噪比计算（`_SNRCalc`，计算内联于 `_on_calc`）

公式（界面公式条）：`Pn(dBm) = -174 + 10*log10(B) + NF    |    SNR(dB) = Pr - Pn    |    N0 = -174 dBm/Hz`。实现：`N0=-174`（dBm/Hz，对应 290 K）；`Pn_dBm = N0 + 10·log10(B) + NF`（B 由 MHz×1e6 得 Hz）；`SNR = Pr − Pn_dBm`；灵敏度 `sens_10dB = Pn_dBm + 10`（SNR=10 dB 最小可检测）；噪声电压 `noise_voltage = √(K_BOLTZ·T·B·10^(NF/10)·50) × 1e6`（μV 有效值，50 Ω 硬编码）。

符号：`B` Hz、`NF` dB、`Pr` dBm、`T` K（**仅进入噪声电压项**，不影响 Pn/SNR）。输入域：带宽/温度 `_positive_value`，噪声系数/接收功率 `_finite_value`；捕获 `(ValueError, OverflowError, ZeroDivisionError)`。输出：N0、Pn、输入功率、SNR、灵敏度、噪声电压（μV）。

## 8. 已知问题与后续计划

### 8.1 已知问题（V1.2.1）

1. 天线口径形状不参与计算：`combo_shape` 仅展示，恒按圆形口径 `A_eff=η·π(D/2)²`；矩形长×宽未实现。
2. 天线增益/作用距离/信噪比计算内联在 `_on_calc`，未抽 `calc_formulas.py` 纯函数（仅链路/测向/阵列已抽），难脱离 Qt 单测。
3. 信噪比固定 −174 dBm/Hz（290 K）：温度输入只影响 50Ω 噪声电压，不参与 Pn/SNR；作用距离硬编码 `T0=290`。
4. 作用距离 10 km 参考点硬编码（`R_10km=10000`）；`4**0.25` 敏感度提示为固定文案。
5. 矩形面阵 X/Y 间距共用隐藏的 `combo_d_unit`（λ/m）做 `_spacing_lam` 换算，易误解。
6. 测向精度为近似模型：单基线干涉仪 + MUSIC「√N 增益」近似，非真实 MUSIC 谱估计；无比幅/ESPRIT/多基线/通道误差。
7. 阵列参数只给栅瓣位置/无模糊范围，不给栅瓣电平。
8. 无实时计算（须点按钮）；`convert_gain_ratio` 仅功率比口径（10·log10），不支持电压比（20·log10）。

### 8.2 后续计划

1. 把天线增益/作用距离/信噪比抽到 `calc_formulas.py` 纯函数并补独立回归测试（延续「公式与 UI 分离」路线）；
2. 补矩形/椭圆口径公式与输入，使 `combo_shape` 生效；
3. 参数扫描、历史记录等高级特性按需增量落地（总体设计文档 §11.2 列为后续方向）；
4. 模型增强（按需求）：大气/雨衰、双站方程、多基线测向、栅瓣电平、温度可调噪声谱密度；
5. 功耗/重量预算等系统级计算器视使用需求排期。
