## 1. 游戏栏整体设计

### 1.1 产品定位

**「科研狗的精神避难所」**

不是大张旗鼓的游戏中心，而是一个藏在角落里的小彩蛋——当你调参数调得头大、跑仿真跑得犯困时，点开来摸5分钟鱼，满血复活继续搬砖。

### 1.2 入口与形态

| 维度 | 设计方案 |
|------|----------|
| **入口位置** | 顶部导航栏最右侧，一个低调的 🎮 图标 |
| **触发方式** | 点击图标，右侧抽屉式滑出 |
| **面板尺寸** | 宽度 360px，高度 100%（不遮挡主仿真区） |
| **关闭方式** | 点击遮罩 / 按 ESC / 再次点击 🎮 图标 |
| **默认状态** | 收起，完全不影响正常使用 |

### 1.3 设计原则

1. **轻量至上**：单局游戏 1-5 分钟，随时可停
2. **主题契合**：所有游戏都和"雷达/信号/阵列"沾边，不违和
3. **无侵入性**：绝不主动弹窗、绝不推送、绝不打扰
4. **进度不丢**：关闭自动暂停，回来继续玩
5. **有小惊喜**：藏几个彩蛋，发现了会会心一笑

### 1.4 游戏选择策略

| 类型 | 游戏 | 定位 |
|------|------|------|
| 🎯 **主题定制** | 信号源猎手 | 门面担当，和DOA强相关，玩了还能学知识 |
| 🧠 **益智休闲** | 频谱2048 | 经典玩法，上手零成本，杀时间神器 |
| 🐍 **反应操作** | 阵列贪吃蛇 | 动动手，活动一下僵硬的手指 |
| 💣 **逻辑推理** | 干扰源扫雷 | 动脑不动手，适合摸鱼装认真 |

## 2. 游戏一：信号源猎手

### 2.1 游戏概述

**一句话介绍**：你是一名雷达兵，用你的天线阵列找出藏在噪声里的信号源！

**核心体验**：紧张刺激的寻宝感 + 潜移默化理解DOA原理

**适合场景**：想动动脑、又不想太累的时候

---

### 2.2 核心玩法

#### 2.2.1 基本操作

```
┌─────────────────────────────┐
│        游戏区域              │
│                             │
│    ⌒⌒⌒⌒⌒                  │
│    (  阵列  )  ←── 旋转控制  │
│    ⌒⌒⌒⌒⌒                  │
│                             │
│         ❓  ← 信号源藏在这里 │
│                             │
└─────────────────────────────┘
       信号强度: ████░░░░ 45%
```

- **鼠标控制**：移动鼠标控制阵列旋转方向
- **键盘控制**：← → 键微调方向，空格"发射"锁定
- **核心机制**：阵列指向信号源时，信号强度条最高

#### 2.2.2 游戏流程

```
第1关（新手村）
    ↓
场景：空旷无干扰
信号源：1个，固定不动
提示：有明显的信号强度指示
目标：30秒内找到信号源
    ↓
通关 → 进入下一关
失败 → 可重试或看答案
```

## 3. 游戏二：频谱2048

### 3.1 游戏概述

**一句话介绍**：经典2048，但方块是频率分量，合并后功率翻倍！

**核心体验**：零学习成本，随手就能玩，杀时间神器

**适合场景**：脑子转不动了，想机械性地摸一会鱼

---

### 3.2 核心玩法

#### 3.2.1 基本规则

- 4×4 网格
- 方向键/滑动移动方块
- 相同频率的方块碰撞后合并，频率×2
- 每次移动后随机生成新方块
- 目标：合出最高频率！

#### 3.2.2 频率数值设计

|------|--------|----------|------|

| 5 | 38.4 GHz | 38.4G | #f67c5f |

| 7 | 153.6 GHz | 153G | #edcf72 |
| 8 | 307.2 GHz | 307G | #edcc61 |
| 9 | 614.4 GHz | 614G | #edc850 |

| ... | ... | ... | ... |

> 💡 **梗点**：合到太赫兹级别了，还能继续吗？—— 当然可以，毕竟是游戏嘛！

---

### 3.3 特色机制

#### 3.3.1 频谱背景

- 游戏网格底部是动态频谱图
- 每合并一个方块，频谱上对应频率位置就会出现一个峰值
- 方块越多，频谱越"丰富"

#### 3.3.2 特殊方块

| 特殊方块 | 图标 | 效果 | 出现概率 |
|----------|------|------|----------|
| **噪声方块** | 〰️ | 不能合并，占位置，用"滤波"技能消除 | 5% |
| **放大器** | 📈 | 合并时×4而不是×2 | 2% |
| **混频器** | 🔀 | 和任意方块合并，取两者平均值×2 | 1% |

#### 3.3.3 技能系统

| 技能 | 效果 | 冷却 |
|------|------|------|
| **低通滤波** | 消除所有频率最低的方块 | 60s |
| **高通滤波** | 消除所有频率最高的方块 | 60s |
| **撤销** | 悔棋一步 | 120s |

## 4. 游戏三：阵列贪吃蛇

### 4.1 游戏概述

**一句话介绍**：贪吃蛇，但蛇身是天线阵元，越长阵列孔径越大，分辨率越高！

**核心体验**：经典玩法 + 阵列梗，越玩越有意思

**适合场景**：想活动一下手指，又不想太费脑

---

### 4.2 核心玩法

#### 4.2.1 基本操作

- 方向键 / WASD 控制蛇的移动方向
- 吃到食物，蛇身增加一节（增加一个阵元）
- 撞墙/撞自己，游戏结束
- 目标：尽可能长！

#### 4.2.2 食物种类

| 食物 | 图标 | 效果 | 出现概率 |
|------|------|------|----------|
| **信号源** | 📡 | +1 阵元，+10分 | 70% |
| **宽带信号** | 🌐 | +2 阵元，+30分 | 15% |
| **干扰源** | ⚡ | 反向移动3秒，-20分 | 10% |
| **校准脉冲** | ✨ | 短暂无敌，可穿墙 | 5% |

---

### 4.3 阵列梗设计

#### 4.3.1 实时显示阵列参数

游戏界面下方实时显示：

```
阵元数: 8 个
阵列孔径: 4.0 λ
理论分辨率: 14.5°
栅瓣风险: 无 ✓
```

> 💡 **知识点**：阵元间距保持半波长时，分辨率 ≈ 50° / 阵元数。玩着玩着就记住了！

#### 4.3.2 特殊机制

**栅瓣惩罚**：
- 如果蛇身转弯太急，导致相邻阵元间距 > λ/2
- 屏幕上会出现警告：⚠️ **栅瓣警告！**
- 同时出现一个"栅瓣鬼"，会追着你跑
- 被追上就 Game Over

**空间平滑奖励**：
- 保持直线移动超过5秒
- 获得"空间平滑"buff，分数×1.5
- 提示：✨ **相干源已解相关！**

## 5. 游戏四：干扰源扫雷

### 5.1 游戏概述

**一句话介绍**：经典扫雷，但雷是干扰源，你要找出所有真实信号源！

**核心体验**：逻辑推理，越玩越上头，适合装模作样摸鱼

**适合场景**：想慢慢摸鱼，不想被人发现是在玩游戏

---

### 5.2 核心玩法

#### 5.2.1 基本规则

- N×M 的网格
- 格子里藏着：信号源 ✅、干扰源 💣、空单元
- 点击格子揭开
- 数字表示周围8格内的**信号源数量**
- 右键标记：
  - 🚩 = 我确定这是信号源
  - ❓ = 不确定
  - 💣 = 我确定这是干扰源
- 目标：揭开所有非干扰源的格子 + 正确标记所有信号源

#### 5.2.2 难度等级

| 难度 | 网格大小 | 信号源数 | 干扰源数 | 预计时间 |
|------|----------|----------|----------|----------|
| 简单 | 9×9 | 10 | 10 | 3-5分钟 |
| 中等 | 16×16 | 30 | 25 | 10-15分钟 |
| 困难 | 16×30 | 60 | 50 | 20-30分钟 |
| 专家 | 30×30 | 100 | 80 | 40-60分钟 |

---

### 5.3 特色机制

#### 5.3.1 信号强度提示

- 每个数字格子不仅显示数字，还会用颜色深浅表示"信号强度"
- 离信号源越近，颜色越深
- 给推理增加额外信息维度

#### 5.3.2 特殊格子

| 格子类型 | 外观 | 效果 |
|----------|------|------|
| **相干源** | 闪烁的数字 | 两个相邻的相干信号源，数字会互相干扰，显示值±1 |
| **多径反射** | 镜像数字 | 这个格子的数字是对面格子的镜像 |
| **盲区** | 灰色格子 | 阵列盲区，无法探测，永远是问号 |

#### 5.3.3 技能系统

| 技能 | 效果 | 冷却 |
|------|------|------|
| **MUSIC扫描** | 揭示一行/一列的所有信号源位置 | 90s |
| **波束形成** | 揭示一个3×3区域 | 60s |
| **人工标记** | 自动正确标记一个信号源 | 120s |

### 6.2 番茄钟联动

**「专注-休息」循环**：

```
┌──────────────────────────────────┐
│  🍅 番茄钟                       │
│  专注 25:00  →  休息 5:00        │
│                                  │
│  [开始专注]                       │
└──────────────────────────────────┘
```

- 专注模式：游戏栏锁定，打不开（可以手动解锁，但会记录"摸鱼次数"）
- 休息时间到：自动弹出"休息一下？"提示，推荐玩一局游戏
- 统计：每天专注时长、摸鱼次数、游戏时长

> 💡 **产品小心机**：用番茄钟给游戏一个"正当理由"——不是我想玩，是科学休息需要！
